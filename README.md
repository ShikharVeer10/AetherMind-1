# AetherMind-1

AetherMind-1 is a Python-based document intelligence project that extracts structure-rich data from presentations, PDFs, and images and exports reconstruction-ready JSON.

## Repository Layout

```text
AetherMind-1/
├── AetherMind-20fbcdb09f19b4b739d4b225a3e8d87e97d8f209/  # main source project
│   ├── agents/
│   ├── extractors/
│   ├── models/
│   ├── services/
│   ├── main.py
│   ├── run_validation.py
│   ├── e2e_extraction_runner.py
│   ├── test_form_extraction_agent.py
│   └── requirements.txt
└── output/                                                # generated outputs/logs
```

## What It Does

- Extracts content and layout from `.pptx`, `.ppt`, `.pdf`, `.png`, `.jpg`, and `.jpeg` inputs
- Preserves geometry, element metadata, and semantic structure
- Produces reconstruction JSON for downstream rendering/validation workflows
- Includes form reconstruction and visual validation utilities

```bash

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

```

## Usage

### Main extraction pipeline

```bash
python main.py <document_path> [--output-dir output] [--first-page-only] [--fast] [--validate] [--report]
```

Examples:

```bash
python main.py ./sample.pptx --output-dir ./output
python main.py ./sample.pdf --first-page-only --report
```

### Validation pipeline

```bash
python run_validation.py <input_path> [--output-dir ./output] [--cache]
```

### E2E extraction report runner

```bash
python e2e_extraction_runner.py <input_path> <output_dir> [--first-page-only]
```

## Running Tests

From the source project directory:

```bash
pytest test_form_extraction_agent.py
```

## Output

The pipeline writes artifacts under the chosen output directory, including:

- `extracted_json/*_reconstruction.json`
- `e2e_report.json` (when `--report` is used)
- rendered validation files (when validation is enabled)

## Notes

- The core implementation currently lives in the nested folder `AetherMind-20fbcdb09f19b4b739d4b225a3e8d87e97d8f209`.
- Existing `output/` files are generated artifacts and can be regenerated by rerunning extraction.
